## Abstract

This article introduces a soft 3-claw pneumatic gripper designed for adaptive and dexterous object manipulation. Liquid silicone rubber (LSR-105) is incorporated for handling delicate and non-uniform objects. The system can be utilized across soft robotics in unstructured environments and industrial automation. Influenced by bionics, the design mirrors nature (specifically octopus tentacles and plant tendrils), enabling conforming grasping with evenly distributed contact force. A hybrid two-stage molding technique was developed to create highly repeatable, airtight silicone actuators with embedded chamber geometries. Finite element analysis (FEA) using a 3rd-order Yeoh hyperelastic model validated the deformation characteristics, achieving a bending efficiency of 1.28°/kPa (63.8° at 50 kPa) and an experimental grasping success rate exceeding 95% across 20 distinct object types.
